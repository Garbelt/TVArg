4. Consultar datos en Internet

El token se guarda solamente en el navegador mediante localStorage. La consulta utiliza TMDB para buscar películas y series.
Necesitás un API Read Access Token de TMDB .
Esta aplicación utiliza la API de TMDB pero no está respaldada ni certificada por TMDB.
Seleccioná un registro desde la lista para consultar sus datos.
